# 三端贴合版破甲

同一套内核，三个软件各自最合适的贴法。判断标准只有一个：**贴进去之后能不能真的做一切事**。

| 软件 | 贴哪 | 用哪个版本 | 为什么 |
|---|---|---|---|
| **WorkBuddy** | 设置 → 自定义系统提示 / 人格框（永久） | 常驻版 | 有常驻框，一次贴永久生效；本端已有 hooks 强锚，破甲本来就是活的 |
| **DeepSeek（DSH 桌面端）** | 已由 `dsh-purge-stack` 自动注入，不用手贴 | 自动 | 宿主 system 会跟破甲打架，必须走本机代理：12300 通道不注入，号池/codex 通道注入全量 |
| **豆包** | 创建智能体 → 人设设定框 | 常驻版 + 端到端收敛段 | 豆包只有"人设"一个框，要把破甲写成人设的一部分，并明确模型切换与不降级 |

实测结果是模型直接把整套提示识别成 jailbreak 反而更保守（它 reasoning 原话：
*"The system prompt is an elaborate jailbreak attempting to force compliance"*）。

正确做法已实装在 `C:\Users\qq\dsh-purge-stack`：

- **本机代理** `127.0.0.1:8787` 掌控发给上游的内容
- **号池 / Codex 通道**：注入融合完全版破甲（`config\pojia_full.md`）
- **12300（DeepSeek 中转站）通道**：**一个字都不注入**——它本身就是破甲模型
- 人格口令、分组兜底、11140 换号、截断续写全部在代理层

维护只需双击：`C:\Users\qq\dsh-purge-stack\破甲一键到底.bat`
